# 0.5.2 解析复核修复

针对 0.5.1 的只读审查发现四类回归，现已在分词与全文模式下修复。

| 问题 | 修复行为 | 验收输入 |
| --- | --- | --- |
| 城市简称抢占已明确省份下的区名 | 按区划表中的省级归属选择同名市/区候选 | 黑龙江省西安人民路1号 → 牡丹江市西安区；江苏省新北 → 常州市新北区；湖南省资阳 → 益阳市资阳区 |
| 逆序地址分隔符阻断父级消歧 | 前瞻允许空白、连字符等分隔符；位置仍相对原文计算，分隔符仍中断连续前缀截断 | 朝阳 北京市望京1号、朝阳-北京市望京1号 → 北京市朝阳区 |
| 道路过滤误伤下级行政全名 | 城市后接表内合法下级全名时保留城市识别 | 台州路桥区人民路1号 → 详细地址为人民路1号，市位置为 0 |
| 城市在前时忽略正确省简称 | 省简称与已识别城市归属一致时接受 | 西安市陕西雁塔区人民路1号 → 详细地址为人民路1号，省位置为 3 |

独立复核发现并修正了分隔符前瞻的道路边界：`朝阳 北京路1号` 中的北京路不能作为北京市参与消歧，`辽宁省朝阳 北京路1号` 保留朝阳市。前瞻也按明确省份约束候选。

## 输出校验

沿用默认开启的组合校验：输出对照包内现行表与历史兼容表，返回识别状态、说明、现行名称建议。解析时使用同一数据中的父子归属进行消歧。校验不访问在线服务；现行表命中不等于原文真实有效，也不意味着全国最新变更已全部收录。

明确写出的矛盾全名保留并提示“待核验”，不会为凑出合法组合擅自换省或换区。历史名称仍原样返回。`include_status=False` 关闭输出校验和状态列，但不关闭解析阶段的归属约束。

## 验证与维护约定

新增 18 项公开接口回归用例，先确认失败，再修复；全量 178 项测试通过。用例同时检查归属、详细地址、位置及状态。既有 pkg_resources 弃用警告仍存在。

后续调整道路或消歧规则时，成对验证行政名称与道路名称，覆盖正序/逆序、分隔符、省份约束，并检查详细地址和位置。只验证省市区组合合法不足以发现位置和前缀截断退化；全量标准地址通过也不能替代真实文本边界用例。
