# 行政区划数据更新记录

核验日期：2026-09-08。更新目的：识别新地址，同时保留此前已支持的旧地址名称。

## 数据版本与口径

- 上游：[AreaCity-JsSpider-StatsGov 2025.251231.260403](https://github.com/xiangyuecn/AreaCity-JsSpider-StatsGov/releases/tag/2025.251231.260403)。2026-04-03 采集，综合国家地名信息库 2025-12-31、腾讯 2025-11-19 和采集当日高德数据。
- 原更新脚本固定使用 `2023.240319.250114`，并不会自动查找最新版本。
- 上游明确缺少和安县、和康县；本次生成的数据也没有岑岭县。转换器中用 `OFFICIAL_SUPPLEMENTS` 补充三个县，后续上游收录同一记录不会重复。
- `pca.csv` 是地址识别用省市区名称表，不含行政区划代码或边界。东莞、中山、儋州、嘉峪关的镇街仍放在区字段。港澳台沿用上游口径。
- 本次核验了已找到的官方变更，并未逐条审核全国所有乡镇街道；不能将核验日期理解为全国数据完整覆盖日期。

## 差异与历史兼容

现行表由 3648 行变为 3643 行：新增 8 条、移出 12 条、去除 1 条重复记录。

新增：和安县、和康县、岑岭县、两江新区、中山南朗街道/民众街道、嘉峪关钢城街道/雄关街道。

移出到 `pca_legacy.csv` 的 12 个名称（该表另有 1 条待核验名称，共 13 条）：

- 东莞：东莞港、东莞生态园、松山湖。
- 中山：南朗镇、民众镇。
- 儋州：国营蓝洋农场、洋浦经济开发区。
- 嘉峪关：镜铁区、长城区、雄关区。
- 重庆：江北区、渝北区。

上游新增的“嘉峪关第一街道”与[市政府现行介绍](https://www.jyg.gov.cn/zjjyg/)的两街道三镇名单不一致，转换器排除该行，兼容表标记“待核验”。

[中山市2021年区划变更公告](https://www.zs.gov.cn/zwgk/zfgb/zfgb202111/szfwj/content/post_1979152.html)核实南朗镇、民众镇撤镇设街道；返回旧名并分别建议南朗街道、民众街道。

上游移除不等于全部名称都已撤销，园区也不等于法定县级区划。这张兼容表只证明这些名称在原版本中可识别。
运行时同时加载现行表与兼容表，同一记录去重；当前表优先。旧名称仍输出原名称，不自动归一化。例如原渝北区部分镇划归北碚区，不能把所有旧渝北地址映射为两江新区。
宁波市江北区保留在现行表中。无省市上下文的同名区仍可能需要 `umap` 消歧。

默认 jieba 词典不能完整切分部分新县、区名称；现在使用独立 tokenizer 加载表内全名，不改变调用方全局 jieba 词典。自定义全局 jieba 词典不再影响本库，需要自定义推断时使用本库现有参数。

## 复现与校验

下载固定 release 的 `ok_data_level3-4.csv.7z`，解压两份 CSV 到任意临时目录，在该目录运行：

```bash
python /path/to/cpca-linch/scripts/update_pca_data.py
```

检查 `pca_new.csv` 差异后再替换 `cpca/resources/pca.csv`。升级上游版本时同时审查官方补丁与历史兼容表，不能自动把所有被删行当作合法区划。

## 结构化提示

`transform` 默认追加 `识别状态`、`说明`、`现行名称建议`，`include_status=False` 可恢复原有输出列。历史/地点分类和说明保存在兼容 CSV 中；按完整省市区元组判断，防止宁波江北区被误标为重庆历史名称。不自动改写原区字段。空值或不完整结果标为未完整识别，矛盾组合标为待核验。状态反映本项目数据记录，不证明任意输入地址真实有效，也不是全国历史区划查询服务。

本轮结果：77 项测试通过；固定输入再次生成的 CSV 字节一致；wheel 构建通过，现行表、兼容表和解析代码与工作区一致。CRLF 为原 CSV 格式，差异检查使用 `git -c core.whitespace=cr-at-eol diff --check`。
