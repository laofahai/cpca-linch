# cpca-linch

从简体中文地址中提取省、市、区，返回 pandas DataFrame；支持部分地址简称、历史名称识别和归属校验。

安装包名是 **`cpca-linch`**，导入名是 **`cpca`**。支持 Python 3.8 及以上版本。
本项目 fork 自 [DQinYuan/chinese_province_city_area_mapper](https://github.com/DQinYuan/chinese_province_city_area_mapper)。

## 安装与快速开始

```bash
pip install -U cpca-linch
```

```python
import cpca

addresses = [
    "广东省中山市南朗街道人民路1号",
    "广东省中山市南朗镇人民路1号",
    "黑龙江省西安人民路1号",
]
df = cpca.transform(addresses)
print(df[["省", "市", "区", "地址", "识别状态", "现行名称建议"]])
```

结果如下（省略 `说明` 列）：

| 省 | 市 | 区 | 地址 | 识别状态 | 现行名称建议 |
| --- | --- | --- | --- | --- | --- |
| 广东省 | 中山市 | 南朗街道 | 人民路1号 | 现行名称 | |
| 广东省 | 中山市 | 南朗镇 | 人民路1号 | 历史名称 | 南朗街道 |
| 黑龙江省 | 牡丹江市 | 西安区 | 人民路1号 | 现行名称 | |

旧名称仍可识别并保留原名。建议现行名称通过单独的列返回，不会直接把“南朗镇”改成“南朗街道”。

## 输出与校验

默认返回七列：

| 列 | 内容 |
| --- | --- |
| `省`、`市`、`区` | 识别或补全的名称；缺少的信息通常为空字符串 |
| `地址` | 去掉连续行政名称前缀后剩余的原文 |
| `识别状态` | 是否命中现行、历史或地点名称，以及歧义、冲突等情况 |
| `说明` | 历史变更依据、候选城市或需要核对的原因 |
| `现行名称建议` | 有明确依据时提供替代名称；没有统一替代关系时留空 |

解析时按表中的上级归属消歧，输出前再对照包内现行表、历史兼容表核验省市区组合。
表在本地加载并缓存，无须为每条地址联网下载。即使区未识别完整，也会检查已识别的省市是否矛盾。

| 识别状态 | 含义 |
| --- | --- |
| 现行名称 | 省市区组合命中本项目现行快照，不能替代实时官方校验 |
| 历史名称 | 已核验的旧行政名称；保留原名，提供变更说明 |
| 历史管理名称 | 旧管理区域称呼，不是现行县级行政区 |
| 地点名称 | 园区、农场等地址地点词，不是县区或镇街 |
| 待核验 | 来源存在疑点，或已识别出的省市区层级互相矛盾 |
| 存在歧义 | 内置默认映射仍有多个城市候选，说明列列出候选；可补城市或传入 umap |
| 未完整识别 | 缺少足够的省市区信息，不能判断是否现行 |

例如 `上海市渝北区` 会提示“待核验”，不会为了得到合法组合而擅自换省。
**“现行名称”只表示返回组合命中本项目快照，不证明原文一定指向该地址，也不能替代实时官方校验。**

`地址` 不是任意位置删去省市区后的字符串：正文前缀、空格或分隔符会中断连续前缀截断。
例如 `江苏省南京市 鼓楼区人民路1号` 的剩余地址仍为 ` 鼓楼区人民路1号`，区字段照常识别。

## 常用选项

### 保持旧版四列输出

```python
df = cpca.transform(addresses, include_status=False)
# 仅返回：省、市、区、地址
```

`include_status=False` 关闭输出状态校验和提示列，解析时的归属约束仍生效。
历史名称仍保留原名，但此时不会返回历史提示。

### 处理重名区县

```python
# 单写朝阳区：沿用内置北京默认值，同时提示“存在歧义”并列出候选城市。
df = cpca.transform(["朝阳区人民路1号"])

# 原文有省份：先按省份限制候选。
df = cpca.transform(["吉林省朝阳区人民路1号"])
# 吉林省 / 长春市 / 朝阳区

# 已知业务中的归属时，显式指定区到市的映射。
df = cpca.transform(["鼓楼区软件大道89号"], umap={"鼓楼区": "南京市"})
```

显式传入有效 `umap` 视为调用方已选择城市；映射不能覆盖原文明确的省份约束。

### 选择匹配模式

```python
df = cpca.transform(addresses)             # 默认分词模式，cut=True
df = cpca.transform(addresses, cut=False)  # 全文扫描，默认 lookahead=8
```

分词模式使用加载了区划全名和显式别名的独立 jieba 词典，不修改调用方的全局词典。
全文模式跳过分词；`lookahead` 控制单次扫描的最大名称长度，过小会漏掉长名称。
两种模式共享归属规则，不能保证某一种对所有文本都更准确。

### 获取原文位置

```python
df = cpca.transform(["黑龙江省西安人民路1号"], pos_sensitive=True)
# 省_pos=0，市_pos=-1，区_pos=4
```

位置从 0 开始，按原文字符计数；推断补全、未在原文中直接识别的层级返回 `-1`。

### 其他参数

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `index` | 自动生成 | 指定输出 DataFrame 的索引 |
| `open_warning` | `True` | 控制无法补全城市时的日志警告，不控制识别状态列 |

输入应为地址字符串集合，如 `list` 或 pandas `Series`；单条地址也请写成 `["地址"]`。

## 数据范围与历史兼容

| 数据 | 当前范围 | 用途 |
| --- | --- | --- |
| [pca.csv](cpca/resources/pca.csv) | 3643 条现行快照记录，含直筒子市镇街 | 现行名称识别和归属校验 |
| [pca_legacy.csv](cpca/resources/pca_legacy.csv) | 15 条历史、旧管理区及地点名称 | 保留旧地址识别，返回分类提示 |
| [pca_aliases.csv](cpca/resources/pca_aliases.csv) | 10 条有来源的显式别名 | 将黔南、呼市、兰坪县等写法映射到全名 |

现行数据基于 [AreaCity-JsSpider-StatsGov](https://github.com/xiangyuecn/AreaCity-JsSpider-StatsGov)
的 `2025.251231.260403` 版本，采集日期为 **2026-04-03**；官方补丁核验日期为 **2026-09-08**，
补充和安县、和康县、岑岭县，包含重庆两江新区。采集及核验日期不代表全国所有最新变更均已收录。

东莞、中山、儋州、嘉峪关的镇街可放入 `区` 字段，例如中山市沙溪镇；该字段并不统一代表县级行政区。
国营蓝洋农场、松山湖等兼容名称标为“地点名称”，不能当作现行行政区划。

兼容表不是全国历史区划全集。南朗镇、民众镇可给出街道名称建议；重庆江北区、渝北区等涉及辖区调整，
需要结合镇街确认现行归属，不提供统一替换建议。详见 [数据来源与变更依据](docs/data-update-2026.md)。

本库不提供建筑物反查、全国历史区划换算或多地点抽取；不返回经纬度、行政区划代码。

## 查询区划关系

```python
from cpca import area_map, province_area_map

# 查询鼓楼区的全部归属（包括南京、徐州、福州等）。
candidates = area_map.get_relational_addrs("鼓楼区")

# 将候选限制在江苏省。
candidates = province_area_map.get_relational_addrs(("江苏省", "鼓楼区"))
# [('江苏省', '南京市', '鼓楼区'), ('江苏省', '徐州市', '鼓楼区')]
```

映射表同时用于现行和兼容名称识别；需要判断名称性质时，请查看 `transform` 返回的状态。

## 开发与数据维护

在仓库根目录运行测试：

```bash
python -m pytest -q
```

更新数据时运行：

```bash
cd scripts
python update_pca_data.py
```

脚本使用固定的 `DATA_VERSION`；升级前修改版本、核对官方补丁，生成 `scripts/pca_new.csv`。
检查差异并通过测试后，再用它替换 `cpca/resources/pca.csv`。
自动下载解压需要 `7z`；也可将手动解压的 `ok_data_level3.csv`、`ok_data_level4.csv` 放在命令运行目录。
