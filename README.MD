# cpca-linch

一个用于从简体中文地址字符串中提取省、市、区信息的 Python 模块。

```python
import cpca

df = cpca.transform(["徐汇区虹漕路461号58号楼5楼", "广东省中山市沙溪镇云汉轻纺城"], include_status=False)
print(df)
```

输出：

```
     省    市    区              地址
0  上海市  上海市  徐汇区  虹漕路461号58号楼5楼
1  广东省  中山市  沙溪镇       云汉轻纺城
```

## 安装

```bash
pip install cpca-linch
```

### 主要改进

1. **行政区划数据更新至 2026-04-03 上游快照，并补充已核验的官方变更**
   - 数据来源：[xiangyuecn/AreaCity-JsSpider-StatsGov](https://github.com/xiangyuecn/AreaCity-JsSpider-StatsGov)
   - 版本：`2025.251231.260403`；官方补丁核验日期：2026-09-08
   - 补充和安县、和康县、岑岭县；包含重庆两江新区
   - 数据范围、来源及限制见 [更新记录](docs/data-update-2026.md)

2. **支持不设区的地级市（直筒子市）的镇街识别**
   - 东莞市、中山市、儋州市、嘉峪关市的镇街现在可以作为区级识别
   - 例如：`中山市沙溪镇` 可正确识别

3. **移除经纬度数据**
   - 简化数据结构，减少包体积

## 数据更新

项目提供了数据更新脚本 `scripts/update_pca_data.py`，可用于后续更新行政区划数据：

```bash
cd scripts
python update_pca_data.py
# 生成的 pca_new.csv 替换 cpca/resources/pca.csv
```

自动下载解压需要 `7z`；也可手动解压，将两个上游 CSV 放在运行命令的当前目录。
脚本使用固定版本，升级时需修改 `DATA_VERSION`、核对官方补丁，并检查生成差异。
采集日期不代表全国所有区划变更均已收录。

`pca.csv` 保存本次区划快照及直筒子市镇街；`pca_legacy.csv` 保留旧区名和原有园区名称，
供历史地址识别。历史地址返回原名称，不自动换算到现行区划，结果不适合直接当作现行区划校验。
默认分词模式使用包含区划全名的独立词典，不修改调用方的全局 jieba 词典。

### 历史地址提示

```python
df = cpca.transform(["中山市南朗镇人民路1号", "重庆市渝北区人民路1号"])
print(df[["省", "市", "区", "识别状态", "说明", "现行名称建议"]])
# 南朗镇：历史名称，建议南朗街道；区字段仍保留南朗镇。
# 渝北区：历史名称，需结合镇街确认现行归属；不提供统一替换建议。

# 已有程序依赖原来的四列输出时：
df = cpca.transform(["中山市南朗镇人民路1号"], include_status=False)
```

| 识别状态 | 含义 |
| --- | --- |
| 现行名称 | 省市区组合命中本项目现行快照，不能替代实时官方校验 |
| 历史名称 | 已核验的旧行政名称；保留原名，提供变更说明 |
| 历史管理名称 | 旧管理区域称呼，不是现行县级行政区 |
| 地点名称 | 园区、农场等地址地点词，不是县区或镇街 |
| 待核验 | 来源存在疑点，或已识别出的省市区层级互相矛盾 |
| 存在歧义 | 内置默认映射仍有多个城市候选，说明列列出候选；可补城市或传入 umap |
| 未完整识别 | 缺少足够的省市区信息，不能判断是否现行 |

兼容表只覆盖本次整理的 15 条名称，不是全国历史区划全集。提示按返回的完整省市区组合判断，
无上下文的重名地名或用户自定义映射仍需核对。提示通过结果列返回，不会为每条地址打印警告。

## 使用方法

### 基本用法

```python
import cpca

location_str = ["徐汇区虹漕路461号58号楼5楼", "泉州市洛江区万安塘西工业区", "朝阳区北苑华贸城"]
df = cpca.transform(location_str)
print(df)
```

### 全文模式（更准确）

```python
df = cpca.transform(location_str, cut=False)
```

### 处理重名区县

中国存在重名的区县（如"朝阳区"在北京和长春都有），可通过 `umap` 参数指定映射：

```python
df = cpca.transform(["鼓楼区软件大道89号"], umap={"鼓楼区": "南京市"})
```

### 获取位置信息

```python
df = cpca.transform(location_str, pos_sensitive=True)
# 返回额外的 省_pos, 市_pos, 区_pos 列
```

## 数据接口

```python
from cpca import area_map, city_map, province_area_map

# 查询含有"鼓楼区"的全部地址
area_map.get_relational_addrs('鼓楼区')
# [('江苏省', '南京市', '鼓楼区'), ('江苏省', '徐州市', '鼓楼区'), ...]

# 查询含有"江苏省"和"鼓楼区"的全部地址
province_area_map.get_relational_addrs(('江苏省', '鼓楼区'))
# [('江苏省', '南京市', '鼓楼区'), ('江苏省', '徐州市', '鼓楼区')]
```
